Supported encrypted JSON envelope

For automatic decryption, upload a UTF-8 JSON file with this structure: 

{
  "version": 1,
  "algorithm": "AES-GCM",
  "kdf": "PBKDF2",
  "hash": "SHA-256",
  "iterations": 210000,
  "salt": "base64-salt",
  "iv": "base64-iv",
  "ciphertext": "base64-ciphertext-with-gcm-tag",
  "mimeType": "text/plain",
  "fileName": "document.txt"
}
